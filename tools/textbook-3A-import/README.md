# CHEM 3A textbook practice questions → Final Boss (2026-11-18)

437 of the 1,052 practice questions in the CHEM 3A textbook (`CHEM3Atextbook/bank/ch01–ch14.json`) were added to Final
Boss CHEM 3A as 3A-402 to 3A-838 (`src: "textbook-3A:<textbook id>"`). The 576 ADAPT homework items were left out,
because putting graded homework answers in a review game would give them away.

**How they were chosen.** Four reviewers screened every question against the general-chemistry half of the ACS
General, Organic & Biological Chemistry exam (`SCREEN_BRIEF.md`). A question was kept only if:
- it is exam-like (not drill or trivial vocabulary);
- it has exactly one best answer, with the math redone;
- it is self-contained;
- it does not duplicate an existing Final Boss question;
- it is not one of several items drilling the same skill.

Decisions with reasons: `decisions-A..D.json`.
