# CHEM 3A textbook practice bank: problems found during the Final Boss import (2026-11-18)

While screening all 1,052 practice questions in `CHEM3Atextbook/bank/ch01.json`–`ch14.json`, the reviewers redid every
calculation. No key is wrong, but these items have a second defensible answer or a weak distractor. All were left
out of Final Boss; each is worth a fix in the textbook bank.

## Two defensible answers
- **c4-055 (I₂O₅):** the key is "diiodine pentoxide", but the distractor "diiodine pentaoxide" is the current IUPAC
  form (IUPAC no longer drops the vowel). Replace that distractor.
- **c4-008 ("Which of these is an acid?", key HBr(aq)):** the distractor NH₄Br contains NH₄⁺, a Brønsted acid, so it
  isn't clearly wrong. Use a clearly non-acidic distractor (e.g. NaBr or KCl).
- **c6-038 (C–H bond, ΔEN 0.4):** the key says nonpolar, but the distractor "polar covalent (ΔEN 0.4)" is right
  under a "nonpolar below 0.4" cutoff. State the cutoff in the stem, or change the distractor.

## Rounding traps (key depends on when you round)
- **c1-112:** 12.5 × 4.2 = 52.5. Round-half-to-even gives 52 m², one of the distractors, while the key is 53 m². Use
  numbers that don't land on an exact half.
- **c1-118:** the key, 1.3 g/mL, holds only if the subtraction (5.54) isn't rounded before dividing. Rounding first
  gives the 1.2 distractor. Say "round only at the end", or change the data.
